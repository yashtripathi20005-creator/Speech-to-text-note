# Speech-to-Text Note Taker

A real-time speech-to-text note-taking application built with Python. Convert your speech to text instantly and manage your notes efficiently.

## Features

- 🎤 **Real-time Speech Recognition**: Converts speech to text as you speak
- ✏️ **Live Transcription**: See your words appear in real-time
- 💾 **Save/Load Notes**: Save your notes and load them later
- 📝 **Multiple Export Formats**: Export as TXT or Markdown
- 🔤 **Auto Punctuation**: Automatic addition of periods and commas
- 📊 **Word Count Tracker**: Keep track of your note length
- 🎨 **User-Friendly GUI**: Simple and intuitive interface
- ⌨️ **Keyboard Shortcuts**: Quick access to common functions

## Requirements

- Python 3.7 or higher
- Microphone
- Internet connection (for speech recognition API)
